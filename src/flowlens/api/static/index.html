Накопительная диаграмма потока

Ширина полосы — сколько задач в фазе на каждый день. Растущая полоса означает затор: задачи входят быстрее, чем выходят. Завершённые скрыты — включите «Готово» в легенде, чтобы увидеть общий объём.

Если приходит больше, чем закрывается, очередь растёт. Разрыв между линиями накапливается, даже когда каждая задача делается быстро.
