Накопительная диаграмма потока

Ширина полосы — сколько задач в фазе на каждый день. Растущая полоса означает затор: задачи входят быстрее, чем выходят. Завершённые скрыты — включите «Готово» в легенде, чтобы увидеть общий объём.

Поступление и закрытие

Если приходит больше, чем закрывается, очередь растёт. Разрыв между линиями накапливается, даже когда каждая задача делается быстро.

Накопленный разрыв

Недельные колебания взаимно гасятся, а устойчивый тренд остаётся. Линия, уходящая вверх, означает, что очередь набирается системно, а не разово — это видно раньше, чем испортятся сроки.

Потери по причинам

Бары — потери времени, линия — накопленная доля. Обычно две-три причины дают 80% простоя: разбор верхней из них окупается больше, чем попытки ускорить саму работу.

Действующие обещания

SLE — вероятностное обещание: «85% таких задач мы делаем за N дней». Оно честнее дедлайна, потому что признаёт разброс, и полезнее, потому что проверяемо. Пока обещание не зафиксировано, порог всегда равен факту, и сказать «не уложились» нельзя.
