# FlowLens

Инструмент анализа потока задач (Kanban) для тимлида.

## Прочитайте это первым

**Весь контекст проекта хранится в скилле `flowlens`**
(`.claude/skills/flowlens/SKILL.md`). Загрузите его сразу, до любой работы
в репозитории — там архитектура, принятые решения с обоснованием, специфика
данных команды, найденные грабли и инварианты, которые нельзя ломать.

Claude Code: `Skill(skill="flowlens")` или `/flowlens`.
Другие агенты: прочитайте файл напрямую.

Не восстанавливайте контекст по коду — часть решений принята вопреки
очевидному варианту, и причины записаны только в скилле.

## Коротко

Python + Postgres + FastAPI + ECharts. Три слоя данных: сырой журнал событий
(неизменен) → решения ядра о времени работы → метрики. Всё производное
пересчитывается из журнала без обращения к источнику.

Целевая система — Jira Data Center, архитектура source-agnostic.

```bash
make test          # 408 тестов
make lint
flowlens serve     # дашборд на :8000
```

Postgres поднят через brew (`postgresql@16`, порт 5432), не Docker.

## Правила

- Язык интерфейса, комментариев и сообщений коммитов — русский.
- Инварианты из скилла проверяются тестами; при доработках не ломать.
- Тестовые фикстуры пересоздают базу — после прогона тестов данные
  нужно перезалить.
